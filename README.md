# banco-agil-agent

Multi-agent banking assistant developed as a technical challenge.

## Engineering foundation

The project uses typed state, automated tests, coverage, linting, static type checking, and
a least-privilege GitHub Actions workflow. Dependencies are locked with `uv` and monitored
with Dependabot.

Privacy and audit decisions, including explicit production limitations, are documented in
[docs/PRIVACY_AND_AUDIT.md](docs/PRIVACY_AND_AUDIT.md).
